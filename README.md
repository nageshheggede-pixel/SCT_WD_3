# QuizNova – Interactive Quiz Game

SkillCraft Technology Web Development Internship – Task 03

## About the Project

QuizNova is an interactive quiz game developed using HTML, CSS, and JavaScript.

The application allows users to answer multiple-choice questions, receive instant feedback, track their score, and view their final result after completing the quiz.

## Features

- Interactive start screen
- Multiple-choice questions
- Instant answer feedback
- Correct and incorrect answer highlighting
- Live score tracking
- Question progress indicator
- Final score display
- Play Again option
- Responsive design
- Modern glassmorphism-inspired user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Live Server

## How to Run the Project

1. Open the project repository.
2. Download or clone the repository.
3. Open the project folder in Visual Studio Code.
4. Open `index.html`.
5. Right-click inside the file.
6. Select **Open with Live Server**.
7. Start answering the quiz questions.
